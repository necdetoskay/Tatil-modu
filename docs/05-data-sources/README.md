# Data Source & Trust Architecture

## Amaç

Tatil Modu içinde kullanılan dış ve iç veri kaynaklarının:

- türünü,
- otoritesini,
- güncelliğini,
- kanıt gücünü,
- kapsamını,
- lisansını,
- çelişki durumunu,
- kullanıcı kararına etkisini

standart biçimde değerlendirmek.

## Mimari sınır

Capability Platform:

```text
veriyi nasıl elde eder, normalize eder ve taşır?
```

Data Source & Trust Architecture:

```text
hangi veriye ne kadar güvenilir,
birden fazla kaynağı nasıl birleştiririz?
```
